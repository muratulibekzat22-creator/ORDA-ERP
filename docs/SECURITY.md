# Безопасность ORDA ERP

## Аутентификация

- Credentials + bcrypt cost 12 для создания и смены пароля; email нормализуется.
- JWT-сессия: максимум 8 часов, Secure на HTTPS, HttpOnly, SameSite и host-only по стандартной конфигурации NextAuth.
- Пять ошибочных входов блокируют учётную запись на 15 минут; отдельный лимит применяется к хешированному IP.
- Успешные и неуспешные входы записываются в `AuthAuditEvent` без паролей и сырого IP.
- Смена/сброс пароля, деактивация или смена роли увеличивает `sessionVersion`, аннулируя старые сессии.
- Временный пароль требует перехода на `/change-password`.

## Авторизация

API — единственный авторитет. Проверка UI или proxy не заменяет `requirePermission` и ownership. DIRECTOR имеет административные права; защита последнего активного директора выполняется в Serializable-транзакции. MANAGER не получает внутреннюю себестоимость, маржу, выплаты, корпоративные/личные финансы и настройки. PARTNER получает только собственные объекты и редактирует только разрешённые производственные поля.

## Защита HTTP и данных

- CSP, `frame-ancestors 'none'`, DENY framing, nosniff, строгая referrer/permissions policy.
- Health endpoint не раскрывает host, environment или имена переменных.
- Ожидаемые ошибки возвращают безопасный русский текст, без stack trace и Prisma detail.
- Финансовые и персональные ответы не кэшируются публично.
- Мутации с денежным/складским эффектом используют транзакции и/или idempotency key.

## Файлы

Blob остаётся private. Загрузка ограничивает размер, MIME, расширение и сигнатуру, очищает имя и создаёт уникальный pathname. Скачивание проходит ownership/permission и задаёт безопасные заголовки. До приёма файлов от внешних клиентов необходим отдельный выбор владельца по антивирусной проверке; сейчас риск снижается закрытым кругом сотрудников и allowlist типов.

## Секреты

Секреты хранятся только в Vercel Environment Variables или локальном игнорируемом `.env.test.local`. Не печатать значения, connection strings, токены и пароли. После bootstrap удалить `FIRST_DIRECTOR_PASSWORD` и по возможности остальные bootstrap-переменные; ротировать пароль. Проверять scope `DATABASE_URL`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL`, `BLOB_READ_WRITE_TOKEN`. Production source maps отключены.
